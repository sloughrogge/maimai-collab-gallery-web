# 数据与隐私说明

这是独立开发者项目，非麦当劳官方产品。

## 数据流

| 数据 | 发往何处 | 应用如何处理 |
| --- | --- | --- |
| 麦当劳 MCP Token | 本应用 API，再转发至 `https://mcp.mcd.cn` | 页面内存保存；刷新、退出或 30 分钟后清除；应用后端不写入数据库或主动记录日志 |
| 城市、公共地标、门店标识 | 本应用 API、麦当劳 MCP | 用于查询门店和菜单 |
| 精确位置（可选） | 本应用 API、Photon | 仅点击定位并授权后，用于识别城市和街道；不写入应用数据库 |
| 城市、店名、地址 | 用户点击后前往高德地图 | 只传公开目的地信息，不传 Token 或个人位置 |
| 官方海报 URL | 浏览器向官方图片域名请求 | 图片请求使用 `no-referrer` |

应用没有自己的一套短信登录，也不会要求用户提供麦当劳密码或短信验证码。麦当劳登录及 Token 申请在官方开放平台完成。

后端实际接触 Token，因此“仅会话使用”不等于“Token 从不离开浏览器”。自托管者应保持 HTTPS，避免代理或平台日志记录 Authorization 头、请求体与敏感数据。各平台仍可能保留正常的网络访问元数据，这不由本应用完全控制。

## 存储与接口

- 不将 Token 写入 localStorage、sessionStorage、Cookie、URL 或分析事件。
- API 响应设置 `Cache-Control: no-store`；跨域仅允许显式配置的完整 HTTPS 来源。
- D1 `service_limits` 表只保存公共反向地理编码服务的下一次允许请求时间，不保存 Token 或坐标。
- 当前 API 只暴露只读查询；没有领券、抽奖、下单或支付入口。

若不希望经过公开站点的后端，可按 README 自行运行完整开源工程。请勿在 Issue 中公开 Token、手机号、验证码、个人定位或订单信息。
